# AI Interview Platform

A comprehensive Django-based web application designed to help users prepare for job interviews through AI-driven resume analysis and mock interviews. Powered by Google's Gemini AI.

## Features

- **User Authentication**: Secure sign-up, login, and user management.
- **Resume Upload & Analysis**: Upload resumes (PDF) and get AI-powered insights, ATS scoring, and feedback.
- **Mock Interviews**: Select a role and practice answering tailored interview questions generated by AI.
- **Progress Tracking**: Track your interview scores, resume improvements, and overall progress over time.
- **Responsive Dashboard**: A clean, modern UI for managing your interview preparation journey.

## Prerequisites

- Python 3.10+
- Virtual environment tool (`venv` or `conda`)

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Arnav-Naive/ai-interview-platform.git
cd ai-interview-platform
```

### 2. Set Up Virtual Environment

It is recommended to use a virtual environment to manage dependencies securely.

```bash
# Create a virtual environment
python -m venv .venv

# Activate the virtual environment
# On Windows:
.venv\Scripts\activate
# On macOS/Linux:
source .venv/bin/activate
```

### 3. Install Dependencies

Install the required Python packages using pip:

```bash
pip install -r requirement.txt
```

### 4. Configure Environment Variables

The project uses `.env` files for secure configuration. Create a `.env` file inside the `ai_interview` directory (where `settings.py` is located) and add your keys:

```env
SECRET_KEY=your_django_secret_key_here
DEBUG=True
GEMINI_API_KEY=your_google_gemini_api_key_here
```

**Note:** If you don't provide a `GEMINI_API_KEY`, the application will run in "Mock Mode" and provide simulated AI responses.

### 5. Database Migrations

Apply the database migrations to set up the SQLite database:

```bash
cd ai_interview
python manage.py migrate
```

### 6. Run the Development Server

Start the Django development server:

```bash
python manage.py runserver
```

Once the server is running, open your web browser and navigate to:
[http://127.0.0.1:8000/](http://127.0.0.1:8000/)

## Project Structure

- `ai_interview/` - Main Django project configuration.
- `ai_interview/users/` - User authentication and profile management.
- `ai_interview/templates/` - HTML templates for the frontend interface.
- `ai_interview/static/` - Static assets like CSS, JS, and images.
- `ai_interview/media/` - Directory for user-uploaded files (e.g., resumes).
